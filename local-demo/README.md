# حساب — النسخة التجريبية المحلية

واجهة عربية RTL قابلة للتشغيل مباشرة من المتصفح، مبنية بدون اعتماد على خدمات خارجية.

## الوحدات الحالية

- لوحة التحكم والعملاء والفواتير والسندات والإنتاج والتقارير.
- تصنيف الأصناف إلى مواد خام ومواد إنتاج وصنف مركب.
- وصفات الأصناف المركبة مع الإصدار وتاريخ السريان والمكونات والكميات والوحدات والهدر وحساب الاحتياج.
- شاشة أوامر التوريد المخزني للمواد الخام ومواد الإنتاج إلى مخزن تحت التشغيل.
- عند حفظ أمر التوريد، يسجل النظام حركة مخزون مرتبطة برقم الأمر، ويحدث كمية الصنف ومتوسط التكلفة محليًا.
- شاشة الصناديق الرئيسية والفرعية والتحليلية؛ الرئيسي تجميعي، والحركة المالية تكون على الصندوق الفرعي أو التحليلي.

## التشغيل

```bash
cd local-demo
./start.sh
```

ثم افتح `http://localhost:4173`.

## ملاحظات مهمة

هذه نسخة MVP محلية. البيانات محفوظة في `localStorage`، وحركة التوريد محاكاة محلية وليست معاملة قاعدة بيانات بعد. قبل الاستخدام المالي الفعلي يجب نقل العملية إلى Transaction على الخادم، وربط `stock_receipts` و`stock_receipt_lines` و`stock_movements` و`stock_balances` بمخطط Drizzle، مع إضافة صلاحيات المستخدمين وسجل التدقيق.

لإعادة البيانات التجريبية، احذف مفتاح `hisabapp-db` من Local Storage للمتصفح ثم أعد تحميل الصفحة.
